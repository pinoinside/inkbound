    Inkbound — motore per librogame in formato JSON.

    Come si scrive un librogame

    Ogni libro è un file .json nella cartella libri/, elencato in libri/manifest.json. Puoi anche caricarne uno a mano con "Carica un libro".

    manifest.json

    {
  "libri": [
    { "file": "il-cuore-di-vetro.json", "titolo": "...", "autore": "...", "genere": "..." }
  ]
}

    Struttura di un libro

    {
  "titolo": "Nome del libro",
  "sottotitolo": "...",
  "autore": "...",
  "usa_statistiche": true,
  "usa_inventario": true,
  "statistiche_iniziali": { "Ingegno": 8, "Coraggio": 8, "Vita": 20 },
  "inventario_iniziale": ["Oggetto 1"],
  "sezione_iniziale": "1",
  "sezioni": { "1": { ... }, "2": { ... } }
}

    usa_statistiche e usa_inventario sono opzionali (default: true). Se un libro è puramente narrativo, impostane uno o entrambi a false: la relativa sezione della scheda personaggio sparirà, e se sono entrambi false l'intera scheda si nasconde.

    Una sezione

    "1": {
  "testo": ["Primo paragrafo.", "Secondo paragrafo."],
  "illustrazione": "https://...jpg (opzionale)",
  "effetti": [
    { "tipo": "aggiungi_oggetto", "oggetto": "Chiave" },
    { "tipo": "modifica_stat", "stat": "Vita", "valore": -2 }
  ],
  "prova": {
    "descrizione": "Prova di Ingegno",
    "stat": "Ingegno", "dadi": 2, "soglia": 9,
    "successo": "5", "fallimento": "6"
  },
  "combattimento": {
    "nome": "Guardiano", "abilita": 7, "vita": 10,
    "vittoria": "8", "sconfitta": "fine_sconfitta"
  },
  "scelte": [
    { "testo": "Vai a nord", "vai": "2" },
    { "testo": "Usa la chiave", "richiede_oggetto": "Chiave", "vai": "3" },
    { "testo": "Sfida la guardia", "condizione": {"stat":"Coraggio","op":">=","valore":6}, "vai": "4" }
  ],
  "finale": false
}

    Per un finale: "finale": true, "esito": "vittoria" | "sconfitta" | "segreto" | "neutro". Operatori di condizione ammessi: >, >=, <, <=, ==, !=.

    Apertura del sito

    Se apri index.html con un server locale (es. python3 -m http.server), il motore legge automaticamente libri/manifest.json e mostra la libreria dei libri disponibili. Se apri il file con un doppio click, il browser blocca questo tipo di lettura: il motore avvia comunque un libro dimostrativo incorporato, e puoi caricare qualunque libro a mano con "Carica un libro".
